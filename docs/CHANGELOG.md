## 0.2.0

- Added authenticated multi-tenant API operation with role-gated write paths.
- Added PostgreSQL repository support, reversible migrations, and tenant-scoped indexes.
- Added the billing regression gate CLI and GitHub Action wrapper.
- Added observability endpoints, structured logs, metrics, and readiness checks.
- Added the multi-tenant console with login, tenant switching, catalog, saved simulations, and invoice explanation views.
- Added simulation caching, performance indexes, and a live load profile.
- Added production compose, release verification, a deploy-from-scratch runbook, and a threat model.
